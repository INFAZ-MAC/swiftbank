# SwiftBank

SwiftBank is a simple banking application built using Java in NetBeans. I am developing it step by step as a learning project.

## Features
- Create a new account
- Login with username and password
- Customer Management
- Open Saving and Current Accounts
- Loan Management
- Cheque Management 
- Deposit money
- Withdraw money
- Check account balance
- View transaction history

## Technologies Used
- Java
- JavaFx
- NetBeans IDE
- Git and GitHub
- SQL client 8.0
- Scenebuilder


## How to Run
1. Clone this repository
2. Open the project in NetBeans
3. Run the main file

Work in progress. More features will be added soon.
